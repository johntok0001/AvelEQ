# Avel EQ

Параметрический эквалайзер для сведения и мастеринга: до 24 полос, динамический EQ, обработка Mid/Side, режимы Zero Latency и Linear Phase. Форматы: VST3 (macOS и Windows), AU (macOS).

## Возможности
- **24 полосы**, 8 форм: Bell, Low/High Shelf, Low/High Cut (6–96 дБ/окт), Notch, Band Pass, Tilt Shelf.
- **Аналоговая точность без задержки.** Фильтры спроектированы по «matched»-методу, поэтому кривые не «сжимаются» у верхнего края, как у обычных цифровых EQ.
- **Динамический EQ** на любой полосе с усилением: порог (Threshold) и диапазон (Range). Срабатывает от сигнала в своей полосе.
- **Стерео-размещение каждой полосы:** Stereo, Left, Right, Mid, Side.
- **Анализатор спектра** до и после EQ, с наклоном 4,5 дБ/окт, как у профессиональных анализаторов.
- **Auto Gain:** громкость сохраняется при сильной эквализации.
- **Прослушивание полосы** (наушники) и режим солирования.
- **Сравнение A/B, Undo/Redo, пресеты** (заводские и свои).
- **Match EQ:** подгоняет тональный баланс под референс. Референс можно «прослушать» через плагин или загрузить файлом (кнопка Load File или просто перетащить аудиофайл на окно плагина). Плагин сам подбирает полосы; есть настройки Amount, количества полос и сглаживания, предпросмотр кривой до применения.
- **Spectrum Grab:** задержите курсор над спектром, и он замрёт и подсветит резонансы с частотой, нотой и Q. Клик по пику сразу создаёт полосу с подходящим Q, её можно тут же тянуть вниз.
- **EQ Sketch:** нарисуйте мышью кривую, которую хотите получить, и Avel EQ сам расставит под неё полосы.
- **Три режима обработки:** Zero Latency, Natural Phase (аналоговые АЧХ и фаза, задержка около 20 мс) и Linear Phase.
- **Настройки анализатора:** разрешение, скорость, наклон, удержание пиков (Peak Hold).

## Управление
| Действие | Как |
|---|---|
| Добавить полосу | двойной клик по графику, или клик по белой кривой (появляется «+») |
| Двигать полосу | тянуть точку: по горизонтали частота, по вертикали усиление |
| Точно | удерживать Shift |
| Изменить Q | колесо мыши над точкой, или тянуть с Cmd (Ctrl на Windows) |
| Включить / выключить полосу | двойной клик по точке |
| Удалить полосу | Alt/Option-клик по точке, или клавиша Delete |
| Выбрать несколько | Shift-клик или рамка мышью; потом их можно двигать вместе |
| Меню полосы | правый клик по точке (форма, крутизна, стерео, динамика) |
| Отменить / вернуть | Cmd+Z / Shift+Cmd+Z (Ctrl на Windows) |

У обрезных фильтров (Low/High Cut) вертикальное движение меняет резонанс (Q).

## Установка
**macOS:** `AvelEQ-<версия>-macOS.pkg`: двойной клик, затем «Установить». Если macOS не даёт открыть файл, зайдите в Системные настройки → Конфиденциальность и безопасность и нажмите «Всё равно открыть».

**Windows:** `AvelEQ-<версия>-Windows-Setup.exe`. Если появится «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

После установки перезапустите DAW и пересканируйте плагины.

## Сборка
- **macOS:** `bash build_mac.sh` собирает плагин и ставит его себе, `bash make_installer_mac.sh` собирает установщик `.pkg` в `dist/`.
- **Windows:** собирается на GitHub (`.github/workflows/build.yml`). После каждого push оба установщика публикуются на странице Releases.
